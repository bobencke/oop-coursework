# OOP Coursework

Object-oriented programming coursework developed in 2024-2025 as part of personal studies and academic exercises, covering small applications in Java and C#.

Includes OOP fundamentals through console applications built in NetBeans, desktop interfaces with Java Swing, data persistence with JPA, and complementary C# exercises.

## Technologies

- Java
- C#
- NetBeans
- Java Swing
- JPA
- Object-Oriented Programming
